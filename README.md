# Панорама GEFU — промежуточный результат

Статическое веб-приложение для каталога GEFU и подготовки заказов в XLSX. Интерфейс, каталог и логика заказа находятся в `index.html`; PHP, API, база данных и серверная логика не используются.

## Текущий статус

- В каталоге 288 позиций. Остатки оставлены временно по согласованию с владельцем проекта; после получения новой складской таблицы их нужно обновить.
- Цена артикула 19085 — 15 290 ₽; цена 10770 — 3 890 ₽.
- Для оформления обязательны организация, адрес магазина, ФИО, телефон и дата. Сначала вводится организация; затем становятся доступны поля ФИО, телефона и даты. Товары и подготовка заказа разблокируются после заполнения всех данных.
- При первом запуске этой версии прежние сохранённые данные клиента, дата и корзина удаляются, чтобы новый заказ начинался с пустых полей. Введённые после этого данные сохраняются в браузере обычным образом.
- После подготовки заказ XLSX скачивается, а страница предлагает Gmail, Яндекс Почту, Mail.ru, Outlook и почтовую программу. Адрес получателя — `s.kuznetsov@lion-trade.ru`; поля и текст письма можно копировать с экрана.
- Клиент вручную прикрепляет XLSX и отправляет письмо. Страница не получает пароль, не отправляет письмо и не хранит заказы на сервере.

## Установка и работа без интернета

1. Разместить файлы этой папки в корне сайта с HTTPS.
2. Открыть сайт онлайн и установить его как веб-приложение.
3. Нажать **«Подготовить каталог для офлайн-заказа»** и дождаться завершения сохранения фотографий.
4. Затем каталог, корзина и создание XLSX доступны без сети. Ссылки на gefu.ru открываются только онлайн.

Открытие `index.html` двойным щелчком подходит для онлайн-просмотра, но не запускает установку PWA и сервис-воркер. Для установки и офлайн-кэша нужна HTTPS-публикация.

## Публикация через GitHub Pages

Нужен новый пустой **публичный** репозиторий с README, например `panorama-gefu`. Не меняйте видимость существующих репозиториев: они относятся к другим проектам.

После загрузки файлов в корень репозитория включить **Settings → Pages → Build and deployment → Deploy from a branch → main → /(root) → Save**. Адрес сайта будет вида `https://<имя-профиля>.github.io/panorama-gefu/`.

## Обновление остатков

Когда будет готова новая складская таблица, загрузить её отдельно. Обновлять количества по точному артикулу и дату остатков. Затем проверить число позиций, дубли и пропуски артикулов, цены и сумму заказа. Синхронизированные исходники из `sources/` не изменять.

## Файлы

- `index.html` — каталог, адаптивный интерфейс, корзина, XLSX и выбор почтового сервиса.
- `manifest.webmanifest` — настройки устанавливаемого приложения.
- `sw.js` — кэширование для офлайн-режима.
- `icons/` — значки приложения.
- `Состояние проекта.md` — контрольная точка с решениями, ссылками и порядком будущего обновления остатков.
